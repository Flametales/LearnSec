FASE 00

Opfrisser & gap audit.

DUUR · 1-2 WEKEN · DIAGNOSE, GEEN LEERSTOF

Gebruik dit als diagnose. De vragen hieronder vinden gaten die je niet wist te hebben. Alles wat wankel is — nu oplossen.

0.1

Netwerk Self-Audit

Kun je zonder aantekeningen:

  • De TCP three-way handshake tekenen inclusief flag-waarden en wat elke ACK bevestigt
  • Uitleggen waarom TCP zowel sequence- als acknowledgment-nummers heeft — de asymmetrie is belangrijk
  • Een DNS-query voor mail.google.com tracen door recursive resolution, inclusief caching, EDNS, DNSSEC-validatie
  • Het verschil tussen TLS 1.2 en 1.3 handshakes uitleggen, en waarom 1.3 RSA key exchange dropte
  • Subnet 10.0.0.0/22 in vier gelijke subnetten en geef broadcast-adressen
Primaire bronnen om mee op te frissen TCP: RFC 9293 · DNS: RFC 1035 + RFC 8499 · TLS 1.3: RFC 8446. Lees ze, vat ze niet samen. Capture eigen verkeer met Wireshark.
0.2

Linux Internals Opfrisser

  • Hoe fork() en execve() echt werken — wat zit in geheugen op elk moment
  • File descriptors — wat lsof je werkelijk laat zien
  • /proc — lees /proc/self/maps en begrijp wat het je vertelt
  • Linux capabilities vs setuid — waarom setuid wordt uitgefaseerd
  • cgroups en namespaces — de basis van containers
Lezen The Linux Programming Interface — Michael Kerrisk. Referentiewerk, hoofdstukken naar behoefte.
0.3

Programmeer-Polish

  • Python: comfortabel met requests, asyncio, socket, struct, subprocess
  • C vloeiend kunnen lezen — nog niet goed kunnen schrijven
  • Git voorbij de basis: rebase, reflog, bisect, hooks
FASE 01

Fundamenten, verdiept.

DUUR · 2-4 WEKEN

Mentale modellen voorbij de bumperstickers, cryptografie die je daadwerkelijk begrijpt, OS-internals op aanvaller-niveau, web op protocol-niveau.

1.1

Mentale Modellen — Voorbij CIA

De CIA-triad is de bumpersticker. De diepteversie:

  • Parkerian Hexad — voegt possession, authenticity, utility toe. Voor supply-chain en integrity-aanvallen waar CIA nuance mist
  • STRIDE (Microsoft) — Spoofing, Tampering, Repudiation, Information disclosure, DoS, Elevation. Standaard threat-modeling vocabulaire
  • PASTA, OCTAVE, LINDDUN (privacy) — weet dat ze bestaan
  • Attack trees (Schneier's framing) — bouw er één voor een echt systeem
  • "Assume breach" — fundamentele verschuiving weg van preventie-alleen denken
Verplichte literatuur Ross Anderson, Security Engineering (3rd ed). Gratis PDF op zijn site. Het belangrijkste security-boek in druk. Hoofdstukken 1-3 minimaal, daarna voor altijd ad-hoc.
1.2

Cryptografie — Echt Begrijpen

Je hoeft geen ciphers uit te vinden. Je moet wel precies weten welk primitief te kiezen, hoe failure modes eruitzien, en hoe aanvallen op constructies werken.

Concepten om te begrijpen

  • AES modes (ECB, CBC, CTR, GCM, XTS) en wat elk lekt. Waarom ECB een meme is. Waarom GCM nonce-reuse catastrofaal is.
  • Block vs stream ciphers — fundamenten
  • KDFs vs hashes vs MACs — drie verschillende jobs, vaak verward
  • Diffie-Hellman — uitleg op wiskundig niveau
  • ECC: Curve25519 vs NIST curves, waarom Curve25519 won
  • TLS 1.3 handshake byte-voor-byte
  • Forward secrecy — wat het betekent, waarom het belangrijk is
  • Public-key signatures: RSA-PSS vs ECDSA vs Ed25519
  • Password hashing: bcrypt → scrypt → Argon2id. Memory hardness als concept.
  • Quantum-dreiging — wat Shor's echt breekt, wat overleeft, PQ-kandidaten (Kyber, Dilithium)
Oefening · verplicht Cryptopals challenges (gratis). Werk minimaal Set 1, idealiter Sets 2-3 door. Je leert meer van het breken van AES-CBC padding oracle dan van elk boek. Er is geen substituut. Ook CryptoHack — gegamifieerd, uitstekend.
Lezen Serious Cryptography (Aumasson) · Real-World Cryptography (David Wong)
1.3

OS Security op Aanvaller-Niveau

Windows internals

  • LSASS architectuur — waarom het de credential goudmijn is
  • Authenticatie: NTLM (challenge-response in detail), Kerberos (TGT/TGS, PAC, S4U2Self/Proxy)
  • SIDs, ACLs, tokens, integrity levels — Mandatory Integrity Control
  • Windows event log structuur — Security log: 4624, 4625, 4672, 4688, 4769, 5145
  • Registry hives waar credentials en persistence verbergen

Linux internals

  • /etc/shadow formaat en crypt(3) algoritmes
  • PAM stack — hoe authenticatie wordt samengesteld
  • SELinux vs AppArmor — label-based vs path-based MAC
  • Capabilities — lees capabilities(7) helemaal
  • eBPF — moderne observability en moderne attack surface
Lezen Windows Internals (Russinovich) — al is het maar Volume 1, de security-hoofdstukken
1.4

Web op Protocol-Niveau

Je hebt HTTP duizend keer gebruikt. Lees het nu als een aanvaller.

  • HTTP/1.1 — RFC 9110 + RFC 9112
  • HTTP/2: streams, HPACK, framing — en de attack surface (HTTP/2 smuggling, HPACK bombing, Rapid Reset)
  • HTTP/3 + QUIC — opkomende attack surface
  • Cookies in detail: SameSite (Strict/Lax/None), __Host- prefix, partitioned cookies (CHIPS)
  • CORS: preflight, credentials, de echte spec — niet de cargo-culted versie
  • CSP: nonces vs hashes, strict-dynamic, waarom de meeste CSP's bypassbaar zijn
  • WebSockets, EventSource, postMessage, SharedWorker — bredere browser attack surface
  • Same-Origin Policy vs Same-Site (verschillend)
  • JWT en zijn zonden (alg: none, key confusion, jku/kid injection); PASETO als veiligere alternatief
1.5

Home Lab — Bouw Het Goed

Installeer niet zomaar Kali in één VM. Bouw een echte omgeving.

Hypervisor

Proxmox (gratis, echte type-1) op een reservemachine indien mogelijk. Anders VMware Workstation Pro of VirtualBox.

Netwerken — geïsoleerd, host-only

  • Aanvaller-netwerk · DMZ · Interne Windows AD · "Productie" segment met gemixte versies

Hosts

  • Aanvaller: Kali + Parrot + een schone Ubuntu met handmatig geïnstalleerde tools zodat je weet wat waar staat
  • Kwetsbaar: Metasploitable 2 & 3, OWASP Juice Shop, DVWA, WebGoat, VulnHub boxes
  • Active Directory: 1 DC + 2-3 member servers + 2 workstations. Bouw dit — AD is de helft van enterprise pentesting. GOAD (Game of Active Directory) is een kant-en-klaar kwetsbaar forest.
  • Monitoring: Wazuh server vanaf dag één. Telemetrie terwijl je aanvalt — je kunt eigen aanvallen retrospectief jagen.
Gewoonte vanaf dag één Elke aanval die je uitvoert, ook bekijken vanuit de defender-positie. Wat heeft Sysmon gelogd? Wat zou een SIEM zien? Deze ene gewoonte compounded enorm.
FASE 02

Offensief, diep.
De grootste fase.

DUUR · 4-6 MAANDEN · WAAR ECHTE SKILL WORDT GEBOUWD

Je kunt niet verdedigen wat je nooit hebt aangevallen. Deze fase herbedraadt hoe je software, netwerken en systemen ziet. Het verandert je permanent.

2.1

Reconnaissance & OSINT

Passief

  • Certificate transparency logs (crt.sh, censys.io) — goud voor subdomain discovery
  • Shodan / Censys / Fofa — schrijf eigen queries
  • GitHub dorking voor leaked secrets — TruffleHog, gitleaks
  • Wayback Machine — oude versies van apps, vaak met verwijderde endpoints
  • LinkedIn voor org charts en tech stack inferentie
  • DNS history (SecurityTrails, dnshistory.org)

Actief

  • nmap mastery — lees Nmap Network Scanning (Lyon, gratis online). Begrijp TCP/SYN/FIN/Xmas/Null scan verschillen. Service detection algoritmes. NSE scripting — schrijf er één.
  • masscan voor internet-schaal werk
  • naabu, rustscan voor snelheid
  • Subdomain enumeration: amass, subfinder, assetfinder — combineer ze
  • HTTP probing: httpx, gowitness voor screenshots
Bruikbare zij-toepassing Trace Labs CTF — OSINT voor vermiste personen. Slijpt skills met humanitaire toepassing.
2.2

Web Application Security — Het Grote Stuk

De belangrijkste attack surface in moderne infrastructuur. Investeer de tijd. 10-14 weken.

De bijbel — verplicht PortSwigger Web Security Academy — doe elke lab. Gratis, wereldklasse, geschreven door de mensen achter Burp Suite. Begroot 100-200 uur. Er is geen substituut.

Injection familie

  • SQLi: error-based, union-based, boolean blind, time blind, OOB (OAST). NoSQLi. ORM-specifieke quirks.
  • Command injection: shell metacharacters, blind variants, OOB exfil
  • LDAP, XPath, SSTI (Jinja2, Twig, Freemarker, Velocity), SSRF als meta-vulnerability

XSS — diep

  • Reflected, stored, DOM-based, mutation XSS (Heiderich's werk essentieel)
  • CSP bypassen — strict-dynamic bypass, JSONP endpoints, dangling markup
  • Same-Origin Policy chaining, postMessage abuse

Authenticatie & Sessie

  • JWT: alg: none, RS256→HS256 confusion, jku/kid injection, zwakke HMAC keys
  • OAuth 2.0 / OIDC: redirect_uri abuse, state CSRF, implicit flow problemen, PKCE
  • SAML: XSW (XML Signature Wrapping), comment injection, raw signature bypass

Access control

  • IDOR — voorbij numerieke IDs, voorspelbare UUIDs, GraphQL field-level
  • Mass assignment / autobinding
  • HTTP method confusion

Moderne klassen — lees het originele onderzoek

  • HTTP Request Smuggling — James Kettle 2019, CL.0 follow-up
  • Web cache poisoning / deception — Kettle
  • Server-Side Template Injection — Kettle 2015
  • Prototype pollution — client-side en Node.js
  • DOM clobbering — Heyes
Tools — master, niet alleen installeren Burp Suite (Community → Pro) — collaborator, intruder, macros, session handling, BApp store (Autorize, Param Miner, Turbo Intruder) · Caido (nieuwer alternatief) · ffuf · nuclei (schrijf je eigen templates) · sqlmap (handmatig eerst). Wordlists: SecLists verplicht.
Lezen, voor altijd The Web Application Hacker's Handbook · Real-World Bug Hunting (Yaworski) · PortSwigger Research blog elke maand · elke Black Hat / DEF CON web track van de laatste 3 jaar · HackerOne Hacktivity en Bugcrowd Disclosure
2.3

Netwerk Aanvallen

  • Layer 2: ARP spoofing, DHCP starvation/spoofing, VLAN hopping (double tagging, switch spoofing), STP attacks
  • LLMNR/NBT-NS/mDNS poisoning — Responder essentieel, begrijp de onderliggende protocollen
  • IPv6 aanvallen (mitm6) — steeds relevanter
  • WPAD attacks
  • SMB: relay attacks (NTLM relay naar LDAP/SMB/HTTP), null sessions, SMB signing
  • Kerberos relay (KrbRelay), unconstrained delegation abuse
  • TLS aanvallen geschiedenis (BEAST, CRIME, BREACH, POODLE, Logjam, FREAK, Lucky13, ROBOT)
  • Pivoting: SSH dynamic forwarding, Chisel, ligolo-ng (huidige best-in-class)

Wireless

  • WPA2 4-way handshake — capture en crack met hashcat
  • WPA3 SAE — Dragonblood attacks (Vanhoef)
  • Evil twin en KARMA — Mana toolkit
  • WPS Pixie Dust · Enterprise wireless (WPA2-EAP) — eaphammer
2.4

Binary Exploitation Intro

De meeste moderne rollen vereisen geen diepe binary exploitation, maar de fundamenten veranderen hoe je over software denkt.

  • x86_64 assembly — genoeg om disassembly vloeiend te lezen
  • Calling conventions (System V AMD64, Microsoft x64)
  • Stack layout, function prologue/epilogue
  • Klassieke stack buffer overflow — schrijf er één vanaf nul
  • Moderne mitigations en bypasses: ASLR + info leaks, NX/DEP + ROP, stack canaries, CFI/CET
  • Format string vulnerabilities
  • Heap basics — glibc tcache en bin structures
Oefening pwn.college (gratis, ASU — uitstekend) · pwnable.kr · ROP Emporium
Lezen Hacking: The Art of Exploitation (Erickson) · The Shellcoder's Handbook
2.5

Active Directory — Op Aanvaller-Niveau

Wat de meeste interne pentests echt zijn. 6-8 weken.

Concepten

  • AD structuur: forests, domains, OUs, trusts (transitive, one-way, external, forest)
  • Kerberos in detail: AS-REQ/REP, TGS-REQ/REP, de PAC, wat gesigneerd is en wat geëncrypt met welke key
  • NTLM overal nog — challenge/response in diepte
  • GPOs en hun abuse surface
  • LDAP queries — schrijf eigen met PowerShell of Python

Attack chain

  • Initial access via phish of exposed service
  • Enumeratie: BloodHound verplicht — leer Cypher queries lezen, schrijf eigen
  • Credential theft: Mimikatz internals (LSASS, SAM, LSA, DPAPI)
  • Lateral movement: Pass-the-Hash, Pass-the-Ticket, Overpass-the-Hash, WMI, WinRM, PSExec, DCOM
  • Kerberos: Kerberoasting · AS-REP roasting · Unconstrained delegation · Constrained delegation + S4U2Self/Proxy · RBCD · Golden/Silver tickets · Diamond/Sapphire (nieuwer)
  • DCSync, DCShadow
  • ADCS aanvallen — ESC1-ESC15 (Schroeder + Christensen "Certified Pre-Owned" paper verplicht)
  • Trust abuse: SID history, cross-forest attacks
Tools BloodHound · SharpHound · Rubeus · Mimikatz · Impacket (secretsdump.py, GetUserSPNs.py, GetNPUsers.py, ntlmrelayx.py — lees de source) · NetExec (opvolger van CrackMapExec)
Lab GOAD (Game of Active Directory) — kant-en-klaar kwetsbaar forest. End to end doorwerken.
Lezen HackTricks AD sectie · ADSecurity.org (Sean Metcalf — de diepste AD security writer)
2.6

Cloud Attack Surface Intro

  • IAM mentale modellen: AWS (policies, roles, STS), Azure (RBAC + Entra ID), GCP (resource hierarchy + service accounts)
  • Veelvoorkomende misconfiguraties: publieke S3 buckets, te permissieve IAM, exposed metadata service (IMDSv1 SSRF chain)
  • Cross-account / cross-tenant aanvallen
  • Container escape en Kubernetes attack surface (Pod Security, RBAC, etcd exposure)
Lab flaws.cloud en flaws2.cloud (gratis, AWS) · CloudGoat (Rhino Security) · HackTricks Cloud · sadcloud

FASE 03

Defensief, diep.
Je hebt aangevallen. Verdedig nu.

DUUR · 4-6 MAANDEN

De asymmetrie die jou waardevol maakt: de meeste defenders hebben nooit echt aangevallen. Jij wel. Gebruik dat.

3.1

Security Architectuur & Moderne Defensie

  • Zero Trust — Google's BeyondCorp paper (2014) is het origineel. Lees het. Dan NIST SP 800-207.
  • Netwerk segmentatie: macro, micro, identity-based
  • Defense in depth goed gedaan — niet "meer controls" maar layered, elk uitgaande van dat anderen falen
  • MITRE D3FEND — defensieve tegenhanger van ATT&CK
  • Cyber Resilience — NIST SP 800-160 Vol 2
  • WAF, RASP, NGFW, SASE — wat elk echt doet en waar elk faalt
3.2

Logging & Detection Engineering

8-10 weken. Het diepe deel van defense.

Logging filosofie

  • Wat loggen, waarom, retentie strategie
  • Cost-aware logging — de meeste orgs over-loggen ruis en onder-loggen signaal
  • Log integriteit, time sync, source authenticatie

Telemetrie bronnen

  • Windows: Event Logs, Sysmon, ETW
  • Linux: auditd, sysmon-for-linux, eBPF (Falco, Tracee)
  • Netwerk: Zeek (voorheen Bro — leer dit, ondergewaardeerd), Suricata, NetFlow/IPFIX
  • Cloud: CloudTrail, Azure Activity Log, GCP Audit Logs, VPC flow logs
  • Identity: Entra ID sign-in logs, Okta system log

SIEM — ken er één diep

  • Splunk — SPL is een eigen taal
  • Elastic Stack (Elastic Security)
  • Microsoft Sentinel — KQL wordt must-know
  • Open source: Wazuh, Graylog, Security Onion

Detection engineering — het ambacht

  • Sigma rules — vendor-agnostische detection taal
  • Detection-as-code: rules in git, getest, peer-reviewed, deployed via CI/CD
  • Pyramid of Pain (David Bianco) — waarom IOC-based detection de zwakste tier is
  • ATT&CK-driven detection — map elke detection naar een techniek
  • False positive economics — de meeste "broken" detections zijn alert fatigue
  • Detection testing: Atomic Red Team, Caldera
Lezen The DFIR Report — gratis, wereldklasse incident writeups. Eén per week, voor altijd. · Florian Roth's blog · Splunk threat hunting · Practical Threat Intelligence and Data-Driven Threat Hunting
3.3

EDR / XDR — Diep

  • Hoe EDR echt hookt: usermode (deprecated), kernel callbacks, ETW Threat Intelligence, AMSI
  • Waarom aanvallers om hooking geven: bypass technieken (direct/indirect syscalls, hellsgate/halosgate, unhooking)
  • Sysmon configuratie: SwiftOnSecurity's template, Olaf Hartong's modular config
  • AMSI internals en bypasses
  • ETW voor defenders (en hoe aanvallers het verblinden)
  • osquery / Velociraptor voor fleet visibility en IR
3.4

Threat Intelligence — Echt, Niet Buzzword

  • MITRE ATT&CK — internaliseren, niet alleen kennen. Memoriseer tactics. Weet welke techniques noisy vs stealthy zijn.
  • Diamond Model (adversary, capability, infrastructure, victim)
  • Cyber Kill Chain (Lockheed Martin)
  • TI lifecycle: direction → collection → processing → analysis → dissemination → feedback
  • IOCs vs IOAs vs TTPs (en waarom TTPs zijn wat je wilt detecteren)
  • MISP voor sharing, STIX/TAXII als standaard
  • Reports kritisch lezen: Mandiant, CrowdStrike, MS Threat Intelligence, Talos, Volexity, ESET, Kaspersky GReAT
  • Attribution skepsis — Thomas Rid, Active Measures
3.5

Incident Response — Praktijk-Niveau

Frameworks

  • NIST SP 800-61r2 — lees het
  • SANS PICERL: Prepare, Identify, Contain, Eradicate, Recover, Lessons
  • John Boyd's OODA loop — past perfect op IR

Disciplines

  • Memory forensics — Volatility 3, MemProcFS. Memory is waar de waarheid leeft.
  • Disk forensics — Autopsy, Sleuth Kit, KAPE voor triage
  • Timeline analysis — plaso/log2timeline
  • Live response — Velociraptor, GRR at-scale
  • Network forensics — Wireshark + Zeek + tshark + Arkime

Windows artefacten cold te kennen

  • Prefetch, ShimCache, AmCache, UserAssist
  • ShellBags, LNK files, Jump Lists
  • $MFT, $LogFile, $UsnJrnl
  • High-value event IDs (4624, 4625, 4648, 4672, 4688, 4697, 4769, 4776, 5140, 5145, 7045)

Linux artefacten

auth.log, syslog, journald, bash history (en hoe aanvallers het neutraliseren), /tmp en /dev/shm staging, persistence (cron, systemd timers, ld.so.preload, kernel modules)

Lezen Incident Response & Computer Forensics (Luttgens/Pepe/Mandia) — standaardwerk · The Art of Memory Forensics (Ligh et al)
3.6

Malware Analyse — Voorbij Intro

8-10 weken.

Statische analyse

  • PE format internals (sections, imports, resources, RICH header, overlay)
  • ELF format internals (program headers, sections, dynamic linking)
  • Strings — herken obfuscaties (XOR, RC4, custom)
  • Imports vertellen verhalen: VirtualAllocEx + WriteProcessMemory + CreateRemoteThread = process injection
  • Ghidra mastery (gratis, NSA-built — juiste startpunt)
  • IDA Free als alternatief · Binary Ninja als betaalbaar

Dynamische analyse

  • Sandboxes: Cuckoo, CAPE, Any.Run, Hybrid Analysis, VirusTotal Enterprise
  • Eigen lab: FLARE-VM (Windows), REMnux (Linux), geïsoleerd netwerk (FakeNet-NG, inetsim)
  • Debuggers: x64dbg, WinDbg (de meeste analisten dodgen het — het is een moat). Leer WinDbg.
  • ProcMon, ProcExp, API Monitor, Wireshark in tandem

Skills

  • Unpacking — handmatig (OEP find, dump, fix IAT), UPX trivially, custom packers
  • Code injection identificatie (klassiek, APC, atom bombing, doppelganging, herpaderping)
  • Anti-analyse verslaan (anti-debug, anti-VM, anti-disassembly)
  • Configuration extraction uit veelvoorkomende families
  • YARA — schrijf rules die families vangen, niet enkele samples

Moderne malware om te bestuderen (in geïsoleerd lab)

  • Trickbot / Emotet — modulaire loaders
  • Cobalt Strike — meest voorkomende implant in echte intrusions. Leer artefacten cold.
  • Sliver, Mythic, Havoc — open-source C2 frameworks
  • Ransomware families (LockBit, BlackCat/ALPHV, Akira)
  • LOLBAS project — living-off-the-land binaries
  • Samples (handel voorzichtig): MalwareBazaar
Lezen Practical Malware Analysis (Sikorski & Honig) — standaard · Practical Binary Analysis (Andriesse) · Rootkits and Bootkits (Matrosov et al)
3.7

Threat Hunting

  • Hypothesis-driven (niet alert-driven) — "als een aanvaller X deed, zou ik Y zien"
  • ATT&CK-driven hunts
  • TaHiTI methodologie — Targeted Hunting integrating Threat Intelligence. Nederlandse oorsprong, ontwikkeld door bankensector.
  • KQL (Microsoft) en SPL (Splunk) vloeiend
  • Hunting in network data met Zeek
3.8

Capstone

  • Bouw een home SOC: Wazuh + Sysmon + Sigma rules + Atomic Red Team executie
  • Voer 20+ ATT&CK technieken tegen je AD lab uit, detect elke, schrijf op
  • Draag een detection rule bij aan een publieke repo (Sigma, Elastic, Splunk SSE)
  • Pursue: BTL1 · GCIH / GCFA (SANS, duur) · CDSA (SANS, nieuwer/goedkoper) · CySA+

NL CONTEXT

Nederlandse & Europese context.

Specifiek voor wie hier werkt en leert: wetgeving, lokale platforms, communities die je in Nederland kunt opzoeken.

// WETGEVING

Artikel 138ab Wetboek van Strafrecht (computervredebreuk) — tot 4 jaar gevangenisstraf; geaggregeerde vormen meer. Kennis hiervan is geen optie.

// RESPONSIBLE DISCLOSURE

Het NCSC heeft een Leidraad CVD — de Nederlandse standaard voor coordinated vulnerability disclosure. Volg deze.

// BUG BOUNTY · NL/BE

Zerocopter (NL) en Intigriti (BE) zijn de regionale platforms naast de internationale HackerOne en Bugcrowd.

// DIVD

Dutch Institute for Vulnerability Disclosure — vrijwilligers-instituut dat Nederlandse infrastructuur scant en RD doet. Goede plek om bij te dragen en te leren.

// CONFERENTIES NL

Hack in The Box Amsterdam jaarlijks · BSides Amsterdam · SANS Amsterdam trainingen

// COMMUNITIES

Nederlandse OWASP chapter · Cyber Crime Unit (NCSC, politie) publicaties · Discord communities zoals NLSec.

KRITIEK

Lees dit elke fase.

Elke skill in dit curriculum is dual-use. Dezelfde port scan die je lab-machine vindt, vindt een ziekenhuisnetwerk. Hetzelfde exploit dat een CTF box popt, popt een echte. De lijn tussen security researcher en crimineel is autorisatie, niet skill.

  • Schriftelijke toestemming, altijd. Mondelinge afspraken overleven geen rechtszaal.
  • Bug bounty programma's zijn je legale speeltuin — HackerOne, Bugcrowd, Intigriti, Zerocopter, YesWeHack
  • Responsible disclosure bij vondsten in het wild — volg de NCSC Leidraad CVD
  • Release nooit malware, zelfs niet "samples"
  • In Nederland: Artikel 138ab Wetboek van Strafrecht (computervredebreuk) — tot 4 jaar; geaggregeerde vormen meer
  • De EU criminaliseert steeds meer "security tools" bezit — ken je lokale wet
  • Bij twijfel — doe het niet, en documenteer waarom
